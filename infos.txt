**Operador Ternário (?:)**

O ternário é uma forma abreviada de escrever instruções `if...else`.
* Realiza a atribuição de um valor a uma variável com base na análise de uma condição.
* Utiliza `?` para indicar o valor caso a condição seja verdadeira e `:` caso seja falsa.
* Sua estrutura é: `condição ? valor_se_verdadeiro : valor_se_falso`.
* É útil para simplificar condições curtas, evitando escrever vários blocos de código.
Ex.:
const categoria = idade >= 18 ? "Adulto" : "Juvenil"
Se idade for maior ou igual a 18, atribui "Adulto"; caso contrário, "Juvenil".
